# Hands-On Machine Learning Classification Workshop

This repository provides a series of hands-on workshop scenarios for learning machine learning classification, using the Wisconsin Breast Cancer dataset as a practical foundation. The scenarios are designed to guide a learner from beginner to advanced topics in a structured, interactive way.

## Workshop Scenarios

The core of this workshop is located in the `scenarios/` directory. The project is structured into a series of modules, each building on the last.

To get started, navigate to the `scenarios/` directory. It is recommended to follow the scenarios in numerical order.

Each scenario's directory (e.g., `01-logistic-regression/`) contains:
*   **`README.md`**: A file explaining the learning objectives, core concepts, and discussion questions for the topic.
*   **`Scenario_X_... .ipynb`**: An interactive Jupyter/Google Colab notebook with "fill-in-the-blanks" coding exercises.

### Scenario List:
1.  **01-logistic-regression**: Your first classifier, covering the basics of linear models, data prep, and evaluation.
2.  **02-random-forest**: An introduction to non-linear models and the power of ensembles.
3.  **03-svm**: Finding the optimal decision boundary with Support Vector Machines and the kernel trick.
4.  **04-xgboost**: High-performance classification with state-of-the-art Gradient Boosting.
5.  **05-neural-networks**: A gentle introduction to deep learning for classification with TensorFlow/Keras.
6.  **06-imbalance-and-shap**: Tackling real-world challenges like imbalanced data and model interpretability.
7.  **07-adversarial-ml**: A deep dive into model security, learning how to fool models and how to defend them.

## Original Files

The original Python scripts (`Tutorial13-14.py`, `Tutorial15-19.py`) and their corresponding notebooks are still available in the root directory for reference. These provide a basic implementation of K-Nearest Neighbors (KNN) and serve as a simple starting point.
